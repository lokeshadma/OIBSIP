# 🛍️ Customer Segmentation Analysis — E-Commerce RFM Clustering

> Segmenting an e-commerce company's customer base into actionable groups using **RFM analysis** and **K-Means clustering**, to help the marketing team run targeted, data-driven campaigns instead of one-size-fits-all promotions.

---

## 📌 Project Overview

This project applies unsupervised machine learning to real transactional data to answer a simple business question: **"Which customers matter most, and how should we treat each group differently?"**

Using **Recency, Frequency, and Monetary (RFM)** behaviour, customers are grouped into distinct segments via **K-Means clustering**, with the optimal number of clusters selected using the **Elbow Method**. Each segment is then profiled and paired with a concrete marketing recommendation.

This is **Task 2** of my Data Science Internship at **Oasis Infobyte**.

---

## 🎯 Objective

- Load and clean raw e-commerce transaction data
- Engineer behavioural features (RFM) at the customer level
- Standardise features and apply K-Means clustering
- Determine the optimal number of clusters using the Elbow Method
- Visualise and profile each customer segment
- Translate clusters into actionable marketing strategies

## 🔬 Methodology

**1. Data Cleaning**
Checked for missing values, duplicate rows, invalid dates, and out-of-range numeric values (e.g. negative revenue/quantity). Dataset was found to be clean.

**2. RFM Feature Engineering**
Aggregated the 5,000 transactions into 989 customer-level records:
- **Recency** — days since the customer's last order
- **Frequency** — total number of orders placed
- **Monetary** — total revenue generated by the customer

**3. Feature Scaling**
Applied `StandardScaler` so that Recency, Frequency, and Monetary (which live on very different numeric scales) contribute equally to the distance-based K-Means algorithm.

**4. Optimal K — Elbow Method**
Fit K-Means for K = 1 to 10 and plotted inertia (within-cluster sum of squares) to find the point of diminishing returns. **K = 4** was selected.

**5. Clustering & Visualisation**
Ran K-Means with K=4, then visualised the segments across three feature-pair scatter plots (Recency–Monetary, Frequency–Monetary, Recency–Frequency) and a standardised cluster-center heatmap.

**6. Cluster Profiling & Business Insights**
Calculated mean RFM values per cluster, labelled each segment, and mapped it to a specific marketing action.

### 💡 Marketing Recommendations

- **🏆 Champions →** Reward with a VIP loyalty tier, early access to new arrivals, and referral incentives. Protect this segment — it drives disproportionate revenue.
- **🙂 Regular Shoppers →** Increase purchase frequency with personalised product recommendations and periodic re-engagement campaigns (seasonal sales, bundles).
- **⚠️ Low-Engagement →** Nurture with a welcome/re-introduction email series and incentivise a next purchase (e.g. "10% off your next order").
- **🔴 At-Risk / Churned →** Launch a win-back campaign with a time-limited discount, and a short feedback survey to understand why they stopped buying.

## 📈 Key Learnings

- RFM analysis turns raw transaction logs into behavioural features that are directly interpretable by non-technical stakeholders.
- Feature scaling is essential before distance-based clustering — without it, Monetary (in the thousands) would have completely overshadowed Frequency (single digits).
- The Elbow Method gives a defensible, data-driven justification for the number of segments, rather than picking K arbitrarily.
- Unsupervised learning becomes genuinely useful only when each cluster is translated into a specific, actionable business decision.
