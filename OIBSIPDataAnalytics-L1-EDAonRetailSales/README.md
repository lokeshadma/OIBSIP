# 📊 Exploratory Data Analysis (EDA) on Retail Sales Data

> **Oasis Infobyte Data Analytics Internship - Task 1**

## 📌 Project Overview

This project focuses on performing **Exploratory Data Analysis (EDA)** on a retail sales dataset to uncover sales patterns, product performance, customer purchasing behavior, and actionable business insights using Python.

The analysis includes data inspection, statistical summaries, time-series analysis, product analysis, correlation analysis, and various visualizations to support data-driven business decisions.

---

## 🎯 Objective

The objective of this project is to:

- Understand the structure of retail sales data.
- Perform data cleaning and preprocessing.
- Analyze sales trends over time.
- Identify top-performing product categories.
- Discover relationships among numerical variables.
- Generate business insights through visualizations.
- Provide actionable recommendations based on the analysis.

---

## 📂 Dataset Information

The dataset contains **5,000 retail sales transactions** with the following attributes:

| Feature | Description |
|----------|-------------|
| Order ID | Unique identifier for each order |
| Order Date | Date of purchase |
| Customer ID | Customer identifier |
| Product Category | Category of purchased product |
| Region | Sales region |
| Quantity | Number of products purchased |
| Unit Price | Price per product |
| Discount | Discount applied |
| Payment Method | Mode of payment |
| Delivery Days | Delivery duration |
| Customer Rating | Customer satisfaction rating |
| Revenue | Total revenue generated |

## 📊 Key Insights

- Revenue fluctuates across different months and quarters.
- Certain product categories contribute significantly more revenue.
- Regional sales performance varies considerably.
- Customer ratings indicate generally high satisfaction.
- Revenue is positively correlated with unit price and quantity purchased.

---

## 💼 Business Recommendations

- Increase inventory for top-selling product categories.
- Launch promotional campaigns during low-sales periods.
- Focus expansion efforts on high-performing regions.
- Optimize popular payment methods for a smoother checkout experience.
- Monitor pricing and discount strategies to maximize profitability.
